# أوبريو | متابعة تعاقدات قطاع الري

منصة ويب للقطاع و33 إدارة. القطاع ينشئ العملية ويخصصها ويراقب التأخير. الإدارة ترى عملياتها فقط، تختار المرحلة، وتعدل الموعد المخطط مع سبب إلزامي.

## التشغيل

```bash
npm install
npx prisma db push
npm run db:seed
npm run dev
```

افتح [http://localhost:3000](http://localhost:3000).

اختبارات قواعد التاريخ والتنبيه:

```bash
npm test
```

## الألوان

الأزرق `#0B6A9A` من شعار قطاع الري، والذهبي من ختم الوزارة كلون تمييز فقط. الخلفية ورق دافئ في الوضع الفاتح، ومياه عميقة في الوضع الداكن.

## البيانات

التشغيل المحلي يستخدم SQLite (`prisma/dev.db`). نفس النموذج لـ SQL Server في `database/schema.sql`، والعلاقات في `docs/operio_erd.mermaid`.

الحسابات التجريبية للعرض. غيّر `AUTH_SECRET` وأوقف الحسابات التجريبية قبل أي استخدام فعلي.
